1.0 Course Preamble & Architectural Scope

This course delivers comprehensive foundational and advanced principles of distributed computing systems, modern cloud orchestration topologies, and decentralized data consensus. Students investigate fundamental trade-offs formalized by the CAP theorem, Byzantine fault tolerance, vector time, and Paxos/Raft consensus algorithms. Practical emphasis encompasses building containerized microservices, horizontal auto-scaling pipelines, and resilient distributed storage engines using cloud-native runtime environments.

4.0 Unit-wise Modular Syllabus & Lab Practicals 5 Units • 42 Theory Hrs + 28 Lab Hrs
Unit I: Characterization of Distributed Systems & Logical Time (8 Hrs)

Models of distributed computation, networking endpoints, Lamport timestamps, Vector clocks, Chandy-Lamport global snapshot algorithm, distributed mutual exclusion.

Unit II: Fault Tolerance & Distributed Consensus (9 Hrs)

Failure modes, crash stop vs. Byzantine faults, Two-Phase Commit (2PC), Three-Phase Commit (3PC), Paxos algorithm, Raft consensus, leader election, log replication.

Unit III: Cloud Storage, Partitioning & Consistency Models (9 Hrs)

CAP theorem and PACELC trade-offs. Consistent hashing, distributed key-value stores (Dynamo, Bigtable), read/write quorums, eventual consistency, CRDTs.

Unit IV: Cloud Microservices, Containers & Orchestration (8 Hrs)

Microservices design patterns, API Gateways, gRPC/Protobuf IPC, Docker runtime internals, Kubernetes cluster architecture, Pod scheduling, and ingress control.

Unit V: Cloud Security, Zero Trust & Laboratory Practicals (8 Hrs + Labs)

Mutual TLS, OAuth2/OIDC, IAM policy enforcement, zero-trust network boundaries. Laboratory assignments: 10 bench experiments using Go, Docker, and Kubernetes.
